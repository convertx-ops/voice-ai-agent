## 🆘 QUICK TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| "Model not found" | Run `ollama pull qwen2.5:3b` |
| "Token invalid" | Check BOT_TOKEN in .env |
| "Voice not working" | Ensure ffmpeg is installed |
| "CORS error" | Check main.py CORS settings |
| "Database locked" | Close other processes using DB |

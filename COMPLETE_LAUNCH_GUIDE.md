## 🆘 TROUBLESHOOTING

**Issue:** Bot not responding
```bash
# Check token
python -c "import requests; r=requests.get('https://api.telegram.org/bot[YOUR_TOKEN]/getMe'); print(r.json())"
```

**Issue:** Ollama model not found
```bash
ollama pull qwen2.5:3b
```

**Issue:** Voice not working
- Ensure ffmpeg installed
- Check audio format (WAV, 16kHz)

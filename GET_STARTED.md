## 🎯 YOUR NEXT 3 STEPS (Do These Now)

### Step 1: Get Telegram Bot Token (5 min)
1. Open Telegram
2. Message @BotFather
3. Send `/newbot`
4. Name it: `Voice AI Coach`
5. Username: `voice_ai_coach_bot`
6. **Copy the token** - you'll need this!

### Step 2: Clone & Test Locally (15 min)
```bash
git clone https://github.com/convertx-ops/voice-ai-agent.git
cd voice-ai-agent
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
ollama pull qwen2.5:3b
copy .env.example .env
# Edit .env and add your BOT_TOKEN
python main.py
python bot.py
```
